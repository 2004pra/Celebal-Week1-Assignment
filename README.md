# Celebal-Week1-Assignment
Summary

This project focuses on basic data exploration and data cleaning using Python and Pandas. The dataset was loaded into a Pandas DataFrame and explored using functions such as head(), shape, columns, info(), and describe().

Missing values were identified and handled appropriately, duplicate records were checked, and unnecessary columns with excessive missing values were removed. Basic filtering and column selection operations were also performed.

Additionally, new derived columns such as quantity, total_amount, and savings were created to enhance the dataset for analysis purposes. Finally, the cleaned dataset was exported as a new CSV file.
